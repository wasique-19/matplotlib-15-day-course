## 🏆 Final Project: E-Commerce Sales Dashboard

A dashboard built from 6,000 synthetic orders across 6 categories and 4 regions.

**Business questions answered**
- How does revenue move across the year?
- Which categories and regions contribute most?
- Is growth driven by more orders or by bigger orders?
- When does each category sell best?

**Key insights**
- Electronics generates about 39% of revenue, and Fashion about 21%.
- Revenue jumps in October and stays high through December.
- Order volume stays roughly flat all year, while average order value rises in Q4, so the festive lift appears to come from bigger baskets (a hypothesis worth testing).
- No single region dominates (22% to 29% each).

Run it with:

```bash
python Day15_Final_Project/dashboard.py
```
